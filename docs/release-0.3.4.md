# 篝火 0.3.4

本版加入 UDP 不通时的 TLS 语音回退和故障诊断记录。Windows 客户端可直接覆盖安装；设置、身份和连接历史沿用原配置。安装包随附声音内核 0.1.2（IPC v2）。服务端协议仍为 v2，存档格式不变。

## 更新内容

- UDP 连续约 8 秒没有有效双向保活时，语音改经已有的 TLS 控制连接传输，界面显示“兼容连接 · 延迟可能增加”；UDP 恢复后自动切回。路径切换不重启声音内核、不重开设备、不重连 TCP。机制与边界见 [TLS 语音回退与诊断记录](tcp-fallback.md)。
- 闭麦、PTT 松开和会话回收会立即撤销尚未写出的 TLS 待发语音；队列有界，排队满 100 ms 即丢弃。
- 通话页“…” → “诊断信息”新增自动故障时间线：保留最近 5 分钟、最多 1800 条，可暂停和脱敏导出，不记录音频、昵称、设备名、地址或密钥。
- 诊断快照新增 APM 状态、设备 I/O 进度、UDP/TLS 健康和接收语音质量。

## 兼容与升级

- **回退需要客户端和服务端都升级到 0.3.4。** 新服务端通过可选能力字段声明支持；任一端是旧版时继续只走 UDP，可以互通。
- 声音内核 IPC 从 1 升至 2。0.3.4 安装包自带配套的 0.1.2 内核；0.3.3 客户端的内核更新检查按 IPC 版本隔离，不会下载 0.1.2。
- 回退仍需要可直连的原生 TCP 端口，HTTP 反向代理不能代替；正常部署仍应放行 20800 的 TCP 和 UDP。
- Docker 部署：发布后 `ghcr.io/parz1/gouhuo-server:latest` 指向 0.3.4，`docker compose pull && docker compose up -d` 即可。
