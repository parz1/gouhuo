# 篝火 0.2.2

本版改进语音发闷和低电平尾音被截断的问题。协议与存档格式兼容 0.2.1，
无需同时升级服务端和所有客户端；要使用新的发送音质，发话者需要升级客户端。

## 语音改进

- 默认 Opus 码率从 32 提高到 64 kbps，保持 48 kHz 单声道、10 ms 帧。
- 编码采用 Audio + Auto，优先保留原声，编码复杂度保持 5。
- 语音激活增加 200 ms 尾音保护，减少短暂停顿和轻声尾音被截断；
  闭麦、松开按键说话仍立即停发。
- 新增高频保留回归测试及 64 kbps 离线对比，诊断报告包含编解码 CPU 用量。

代价：合成诊断中含 IPv4 的单路上行约 110 kbps，旧配置约 78 kbps。
本版尚未经过同设备真人竞品盲听，不能仅凭码率宣称听感达到 Oopz/KOOK。
具体测量、条件和限制见 [音质记录](audio-quality.md)。

## 安装与更新

Windows 用户下载 `gouhuo-setup-0.2.2.exe`，退出篝火后安装即可覆盖升级。
安装包未签名，Windows 可能显示 SmartScreen 提示。

**目前实现的是自动检查更新，不是自动下载安装。** 默认启动后约 5 秒检查
GitHub 正式版；发现新版本会显示提示，点击“去下载”打开发布页，再手动下载和安装。
草稿、预发布及网络请求失败不会显示新版本提示；设置中可以关闭启动检查。
尚未实现后台下载、安装包校验、自动替换、重启升级及回滚。

服务端可下载 `gouhuo-server-0.2.2-windows-x64.exe`，或使用
`ghcr.io/parz1/gouhuo-server:0.2.2`。正式发布后 `latest` 随发布流水线更新；
服务器升级仍需主动 pull 和重启。
