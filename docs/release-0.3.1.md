# 篝火 0.3.1

本次补丁调整语音故障恢复，减少网络中断期间音频设备被反复重开的情况，并新增 Linux 静态服务端包。

## 修复与改进

- 仅 UDP 不通时继续使用当前音频设备和套接字探测，持续失败再执行有限的认证重连；设备错误仍走音频恢复流程。
- 短暂恢复不会清空整条连接的重连冷却时间，避免链路反复波动时频繁重连。
- 语音 UDP 地址固定到已认证 TCP 连接的实际对端 IP，并与会话密钥一起更新，避免域名解析变化导致语音发往另一台服务器。
- 实际地址在 TCP 连接成功时保存，避免握手完成后再查询 Windows socket 对端地址引入额外连接失败。
- 控制连接的读、写与取消共享同一个 TCP 句柄，保持超时和关闭状态一致，并继续支持不等待 TLS 写锁的断开。
- 诊断增加语音端点与收发方向错误，便于定位声音中断。
- Linux 服务端补齐 UDP 接收缓冲设置，新增 x64 musl 静态压缩包；修复 IPv6 UDP 唤醒边界。
- 开发工具新增无界面语音机器人，支持循环 WAV、回声、丢包 / 抖动 / 单向中断，以及分批登录和指定发言者数量。

## 下载与升级

Windows 用户下载 `gouhuo-setup-0.3.1.exe` 安装；服务端可使用 Windows 单文件程序、Linux 静态包或 `ghcr.io/parz1/gouhuo-server:0.3.1`。

安装包未签名，Windows 可能显示 SmartScreen 提示。保持现有身份、设置与服务端数据目录；本次没有协议版本或存档格式变更。

## 验证范围

真实服务端测试覆盖加密语音、单向中断、有限重连和恢复。本机 8 / 32 / 64 人、两人发声的九种场景均正常结束，无 TCP 重连或音频重试；12 秒上行中断结束后最慢约 1.15 秒恢复。完整结果见 [压测记录](https://github.com/parz1/gouhuo/blob/v0.3.1/docs/bot-stress-2026-10-04.md)。

32 / 64 人全部同时发声的同机负载仍出现明显欠载与重连，不作为容量通过结果。虚拟声卡相关反馈难以复现，尚未在反馈用户设备上验证；本版包含针对恢复行为的修复，不保证所有声音中断原因已解决。
