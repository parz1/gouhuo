# 篝火 0.3.3

本版交付新版设置和连接历史，供日常使用及小规模通话反馈。Windows 客户端可直接覆盖安装；设置和身份沿用原配置。声音内核仍为 0.1.1，服务端协议保持兼容。

## 更新内容

- 设置采用左侧纵向分类，支持窄窗口滚动和键盘导航。
- 更新页显示当前版本、检查进度、失败重试和可用更新，启动提醒及下载入口接入官方 R2 更新源，失败时回退 GitHub。
- 设置新增“连接历史”，默认记录加入、连接失败、断线、重连等待、恢复及离开；无需提前开启诊断，重启后仍可查看最近 7 天、最多 512 条记录。
- 历史区分本机观测与服务端明确告知；未知原因保持明确。支持脱敏导出和确认后清除，队列、磁盘或清除失败会显示提示。
- 修复通话界面状态投影与布局验收中发现的问题，以及语音进程回收后认证失败被误显示为空闲的竞争问题。

## 下载与更新

从 [v0.3.3 Release](https://github.com/parz1/gouhuo/releases/tag/v0.3.3) 下载 `gouhuo-setup-0.3.3.exe`。发布后官方更新源同步安装包和版本清单。服务端同时提供 Windows 可执行文件、Linux x64 musl 静态包与版本化容器镜像。

完整 Windows 安装包使用严格小于 20 MB 的构建门禁，60 MB 产品线保持不变。具体资产大小和校验值以发布产物为准。

## 当前范围

连接历史目前覆盖客户端控制连接。语音通路、设备及引擎事件、服务端共享关联标识和复制摘要继续在 #47 实现；#47 保持开放。

跨屏与 Windows 系统 DPI、真人试听、完整旧版性能配对及全屏游戏验收仍在后续清单中。本版不宣称 UI CPU 已优化或性能验收全部通过。已有 UI 和资源验证见 [检查记录](ui-validation-0.3.3.md)。
