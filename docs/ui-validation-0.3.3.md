## 离线原生绘制成本隔离工具（2026-10-06）

`cargo build --locked --release -p client --example call_ui_window` 后，执行该示例并传入 `--measure-render-cost`，依次测静态画面、10 Hz 场景更新、20 Hz 合成输入电平、两者共同更新。每组预热 2 秒、采样至少 10 秒，全部结束后窗口自动退出；`GOUHUO_RENDER_COST_OUTPUT` 可指定 JSON 输出文件。测量时需要显示窗口，保持不遮挡、不缩放、不最小化，不进行并行编译。示例不连接网络、不开声卡、不读取用户身份或偏好。

每组在预热后取得实际物理尺寸和比例，逐个采样检查尺寸、比例、可见性、最小化及设置页状态；未满足的样本标为无效。CPU 是自身进程用户态与内核态耗时占一个核心的比例，不含引擎或 GPU。没有持续验证前台及遮挡，合成电平和固定成员布局也不能替代真实通话性能验收。

首次启动方式隐藏窗口，四组样本的可见性标记均为 false；证据保留于 `target/issue-44/render-cost/default.json`，不用于验收或性能结论。修正后另存有效实验，不覆盖失败记录。生产渲染器尚未修改。
