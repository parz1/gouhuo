# 连接历史与原因模型（#47，进行中）

当前已接入结构化原因和默认异步历史存储，尚未交付完整连接历史界面、服务端关联及全部故障通路记录。

## 已接入

protocol::connection 定义稳定的 ConnectionReason、EvidenceSource 与 ConnectionCause。原因码由类型或协议枚举产生，不从翻译后的文案、服务端自由文本推断；导出用 code()，不依赖 Rust Debug 格式。LocalObservation 表示本端看到的事实，ServerConfirmed 表示服务端明确告知；超时不代表服务器崩溃或用户拔网线。UserAction 为后续主动退出/取消事件保留。

ConnectError::connection_cause() 对连接失败、TLS、证书、协议及认证拒绝进行分类，不携带地址、邀请、错误明细或服务端自由文本。未说明的拒绝和 Goodbye 保留 Unknown；读取时的 UnexpectedEof 记为 ReadError，不误当作正常远端关闭。

Ended::Refused 保留 cause：服务端 Goodbye 映射踢人、封禁、同身份替换；重连遇到不可重试的 ConnectError 也保留结构化原因。现有用户文案及重连策略未改，UI 消费端继续显示原有说明。此阶段没有改变线上 protobuf 字段。

## 重连原因接入（第二阶段）

Event::Reconnecting 新增 cause，分别记录本端读错误、正常读取 EOF、写入失败、心跳静默超时、消息长度越界、控制队列背压/不可用，以及请求重建传输。每次重试的失败从 ConnectError 取结构化原因；等待时间、次数和原有中文说明继续保留。主动请求重建记为本端观察，不能据此断言是谁点击或哪个设备失效。

连接内部在同一锁下保存第一份说明与原因；关闭 socket 导致的后续读写失败和重复心跳超时不能覆盖原始故障。真实 TCP 黑洞测试断言首轮 heartbeat_timeout/LocalObservation；请求重建测试断言 transport_restart_requested/LocalObservation；真实阻塞写入造成队列满后验证 control_backpressure 不会被后续写入失败覆盖。54 项核心测试及 8 项重连集成测试通过。尚未加入历史保存、尝试关联或 UI 时间线，此阶段不构成 #47 完成。

## 默认历史与跨重启保存（第三阶段）

客户端启动后默认创建独立历史写线程，不依赖提前开启详细诊断。加入准备、等指纹/加入码、初次失败、已连接、重连等待、恢复、取消、离开和应用退出已经接线。新加入使用随机 128 位 journey，应用启动使用随机 run；字段包含 UTC Unix 毫秒、同 run 内单调耗时、前后阶段、连接代次、重试次数、等待时间、会话号、版本与原因/来源。恢复和等待事件携带发生时的会话号，不能延迟读取 Client 的当前新会话来给旧事件标号。旧 Client 事件仍受原有实例及 join_generation 检查约束。

记录类型没有地址、身份、昵称、邀请、聊天、音频、密钥、设备名或任意文本字段；从磁盘读取拒绝未知字段和未知枚举。当前 JSON 是客户端本地格式，与线上 protobuf 分开；protocol 的 connection-serde feature 只用于受限元数据序列化。

### 保留与写入

- 内存与当前可见历史保留最近 512 条、7 天内事件；时钟回拨时不按 UTC 排序，单调耗时仅在同 run 内比较，未来 UTC 记录仍受条数上限约束。
- 位于 settings.txt 同目录的 connection-history.json 与 connection-history.previous.json 各最多 512 条、1,000,000 字节；恢复文件是上一代快照。每次写入过滤过期记录，两份均遵守时间和条数限制；启动及每分钟空闲检查会清理已过期事件。
- 两个固定临时文件分别不超过 1,000,000 字节。先 sync 文件，再采用现有 Windows MoveFileEx / Unix rename 原子替换；更新恢复代次后再更新主代次，启动选择有效且序号最新的完整快照，不拼接重复记录。损坏主文件可读取恢复快照。
- 清除异步排队，并将两个快照写为空；接受排队不代表磁盘完成。失败显示 clear_failed，不能宣称清除成功。当前尚未提供产品清除按钮。
- 后台队列上限 128，调用者使用 try_send。丢弃事件、拒绝命令、磁盘故障次数和损坏文件分别计数；磁盘故障保留内存记录，通话不以保存成功为前提。故障计数当前属于本次进程，不宣称已经跨重启累计保存。
- 正常应用退出在事件循环结束后释放历史句柄，最多等待后台线程 2 秒；超时打印未写完提示，不无限等待。突然杀进程仍可能丢失尚未写完的排队事件。

现有诊断摘要显示最近 20 条、阶段/代次/重试/原因来源及保存故障。它仍混合现有设备与连接诊断，不作为完整脱敏导出；独立历史查看、离线入口、用户清除确认、便于阅读的日期与原因、完整导出待实现。

六项真实存储测试覆盖重启保持、两代清除不恢复、磁盘不可写、队列满、UTC 回拨/条数边界、损坏主文件恢复与敏感字段拒绝。重连集成测试覆盖旧/新会话号随事件固定；存储测试不替代实际界面与服务端关联验收。
